# 知识文库与资源管理系统需求计划

## 概述
在现有协同笔记与文件存储基础上，构建团队级知识文库，让师生能够上传、管理、预览和协作编辑各种学习资料，实现知识的系统化沉淀与复用。

## 核心需求
- 支持 PDF、Word、PPT、图片等多格式文档上传，上传后自动生成可在线预览的版本。
- 基于文件名、内容标签和历史分类习惯，自动将文档归入合适的知识目录，也支持手动调整。
- 每次修改文档都会保留历史版本，可随时回溯到任意旧版本，并查看不同版本之间的差异。
- 在文档预览界面，用户可以像批改作业一样在任意位置添加标注和评论，并且多位同学同时查看时，标注能即时互相同步。
- 全文搜索：输入关键词即可搜索到文档名称、正文中的内容，快速定位所需材料。
- 权限控制：老师或管理员可以设定某些文档仅特定班级可见，或者开放给所有人只读、可编辑等。
- 管理后台可创建多级分类，审核公开文档的内容，批量管理资源。

## 技术约束
- 复用现有用户体系和权限模型，新增文档、版本、标注相关的数据表。
- 文件存储可沿用阿里云OSS或本地磁盘。
- 实时批注同步基于现有协同通道。
