# 学习积分兑换商城需求计划

## 概述
将现有积分系统升级为可兑换的虚拟商城。学生通过学习行为（练习、发帖、帮助他人、连续打卡等）获取积分，积分可在商城兑换虚拟道具（自习室主题、专属徽章、首页挂件等），甚至线下实物，激励持续学习。

## 核心需求
- 商品管理：管理端可上架商品，设置积分价格、库存、兑换开始结束时间、限购数量。
- 商品类型：虚拟装扮（头像框、名片背景、自习室皮肤）、功能特权（解锁更高清的录屏、查看谁看了我的主页）、实物（书籍、文具，需填写收货地址）。
- 兑换流程：用户浏览商品，点击兑换，扣除积分，生成兑换订单，虚拟商品即时生效，实物商品进入待发货状态。
- 订单管理：用户可查看自己的兑换历史、物流信息；管理员可处理发货、填写快递单号。
- 积分明细：兑换记录计入积分流水，可溯源。
- 积分不足提醒，支持部分支付（积分+现金扩展点）。
