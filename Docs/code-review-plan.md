# 实时协同代码评审系统需求计划

## 概述
在已有代码执行沙箱和协同编辑能力的基础上，构建多人实时代码评审环境。支持用户提交代码片段，评审者可以同时查看、添加行级批注、讨论，所有操作实时同步，并集成代码运行测试。

## 核心需求
- 评审房间：类似视频自习室，可创建评审房间，邀请成员，房间内有代码编辑器（Monaco）和批注面板。
- 协同编辑与批注：基于 Yjs 实现代码文本协同编辑（评审者只读或建议模式），支持行级评论，评论锚定到具体代码行。
- 实时同步：光标位置、批注、聊天消息通过 Socket.IO 或 Yjs 通道同步。
- 版本比较：可提交多次版本，展示 diff 差异。
- 集成沙箱：在评审中可针对任意版本快速运行测试用例，结果回显到面板。
- 状态流转：待评审、评审中、已完成、需修改等，驱动权限变化。
- 整合通知与社区：评审结果可生成摘要帖，关联社区相关帖子。

## 技术约束
- 后端新增 CodeReview、ReviewFile、ReviewComment 模型。
- 协同编辑器复用现有 Yjs + Monaco 集成，需改造为支持只读/建议模式。
- 权限：评审创建者、评审员、旁观者角色。
